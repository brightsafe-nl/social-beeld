# Brightsafe social, beeld

Gerenderde postbeelden voor de Brightsafe-kanalen.

**Deze repository is publiek, en dat is met opzet.** Instagram accepteert geen upload van
beeldbytes: Meta haalt het beeld zelf op bij een publieke HTTPS-URL op het moment van
publiceren. Daarom staan de eindbeelden hier, bereikbaar via `raw.githubusercontent.com`.

Wat hier **niet** hoort: concepten, planning, nog niet goedgekeurde teksten en ruwe
bronopnames. Die staan in de privé-repo `social-content`.

Elk beeld staat er twee keer in. PNG voor LinkedIn, JPEG voor Instagram, want Instagram
accepteert uitsluitend JPEG.

Gemaakt met `scripts/beeld-maken.py` uit `social-content`.
